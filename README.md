# LeadDesk Mini 🚀

LeadDesk Mini is a full-stack lead capture and management application.

It allows users to submit their requirements through a public landing page and provides an admin dashboard to manage leads.

---

# Features

## Public Side

- Landing page
- Lead capture form
- Name validation
- Email validation
- Budget selection
- Message validation
- Data stored in database


## Admin Side

- View all leads
- Search leads
- Update lead status

Lead Status:

- New
- Contacted
- Closed
